Quick Start

<!-- For local testing --> <script src="http://localhost:3001/chat-widget.js"></script> <!-- For production --> <!-- <script src="https://yourdomain.com/chat-widget.js"></script> --> <script> RealEstateChat.init({ userId: '5fde0e22-f518-46d1-a8c6-235215e8762f', replicaUuid: '7779023f-23e6-426d-ab91-f3d0fef67e83', position: 'bottom-right', theme: 'auto', primaryColor: '#3cacae' }); </script>

Configuration Options

userId (required) - Your existing Sensay user ID
replicaUuid (required) - Your existing Sensay replica UUID
position - Widget position: 'bottom-right', 'bottom-left', 'top-right', 'top-left'
theme - Theme: 'light', 'dark', or 'auto' (follows system preference)
primaryColor - Primary color in hex format (e.g., '#3cacae')
